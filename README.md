# 日本の賃金データ可視化

都道府県・年齢・産業別の賃金データを、Streamlit上で地図やグラフとして確認する分析デモです。リポジトリ内のCSVを読み込み、地域や集計年を切り替えて比較できます。

## 主な可視化

- 2019年の都道府県別一人当たり賃金をヒートマップで表示
- 選択した都道府県と全国の賃金推移を比較
- 年齢階級別の賃金・賞与を年ごとに確認
- 産業大分類ごとの賃金項目を集計年別に比較

## 技術要素

- Python、Streamlit、Pandas
- PyDeckによる地図表示
- Plotly Expressによるインタラクティブなグラフ
- CSVの読み込み、結合、条件抽出、集計

## セットアップと起動

リポジトリのルートで依存パッケージをインストールします。

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install streamlit pandas numpy matplotlib pillow pydeck plotly
streamlit run 2-3.py
```

## データについて

`csv_data/` に全国・都道府県別、産業別の賃金データCSVが含まれています。

地図表示では、リポジトリのルートにある `pref_lat_lon.csv` も読み込みます。このファイルは現在リポジトリに含まれていないため、実行前に用意してください。列名は `pref_name`、`lat`、`lon` を使用します。

## 主なファイル

| パス | 内容 |
| --- | --- |
| `2-3.py` | ダッシュボード本体 |
| `csv_data/` | 賃金データCSV |
| `pref_lat_lon.csv` | 地図表示用の都道府県名と緯度・経度（別途用意が必要） |

本アプリはデータを探索・比較するためのデモです。表示値や分析結果の利用にあたっては、元データの定義と対象期間を確認してください。
